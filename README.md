# Countdown

Schöne Countdowns für deine wichtigen Termine – läuft komplett im Browser, nichts verlässt dein Gerät.

**Live:** https://hilalnassrat.github.io/countdown/

## Funktionen

- Beliebig viele Countdowns, der nächste groß im Fokus
- Tage · Stunden · Minuten · Sekunden live, Fortschrittsbalken seit dem Anlegen
- Schnellwahl (morgen, 1 Woche, 100 Tage, Jahreswechsel)
- Teilen per Link – der Empfänger bekommt den Countdown in seine Liste
- Hell- und Dunkelmodus automatisch

## Technik

Eine einzige `index.html`, keine Abhängigkeiten außer der Schrift Plus Jakarta Sans. Speicherung in `localStorage`.
